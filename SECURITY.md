# Security Policy

This repository is a fork of [mugnavo/cove](https://github.com/mugnavo/cove).

- Vulnerabilities in the **original project**: please report them upstream, following the policy at <https://github.com/mugnavo/cove/security>.
- Issues specific to **this fork** (CI, configuration, changes made here): open a private advisory via the **Security** tab of this repository.
